# 🏓 MasaTenisim

Masa tenisi turnuva yönetimi, dinamik ELO/sıralama sistemi, oyuncu istatistikleri ve kulüp operasyonları için geliştirilen modern platform.

---

## 📁 Proje Dokümantasyonu & Analiz Dosyaları

Projenin tüm mimari ve iş analizi detayları aşağıdaki dokümanlarda eksiksiz olarak hazırlanmıştır:

- 📋 **[PROJE_IS_ANALIZI.md](./PROJE_IS_ANALIZI.md)**: Detaylı gereksinim dokümanı (SRS), v1/v2 sürüm kapsamı, turnuva motoru kuralları, ELO formülasyonu ve Store onay rehberi.
- 🗄️ **[VERITABANI_MIMARISI.md](./VERITABANI_MIMARISI.md)**: PostgreSQL / Supabase için ilişkisel veritabanı şeması, SQL DDL scriptleri, RLS (Row Level Security) politikaları ve optimizasyon indeksleri.
- 🏗️ **[KOD_PROJESI_DIZINI.md](./KOD_PROJESI_DIZINI.md)**: Frontend (React Native / Expo), Web Admin (Next.js) ve Backend servislerinin modüler klasör mimarisi.
- 📝 **[GELISTIRME_NOTLARI.md](./GELISTIRME_NOTLARI.md)**: MVP geliştirme yol haritası, sprint planı ve teknik kararlar.

---

## 🛠️ Teknoloji Yığını

- **Mobil Uygulama:** React Native (Expo) + TypeScript + NativeWind
- **Web Admin:** Next.js + TypeScript + Tailwind CSS + Shadcn UI
- **Veritabanı & Backend:** PostgreSQL (Supabase / Prisma) + Node.js / FastAPI
- **Dağıtım:** Expo EAS, Vercel / Cloudflare
